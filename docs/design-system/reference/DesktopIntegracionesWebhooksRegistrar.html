DirecciónEs la dirección pública de Agentry ahora mismo. GitHub firma cada aviso con el secreto; Agentry lo comprueba antes de leer nada.
Eventos
  • pull_requestUna PR se abre, cambia o se cierra
  • pull_request_reviewAlguien envía una revisión
  • pull_request_review_commentUn comentario en el diff
  • pull_request_review_threadUn hilo se resuelve o se reabre
  • check_runUna comprobación cambia
  • check_suiteUn conjunto de comprobaciones termina
  • workflow_runUn workflow empieza o termina
  • issue_commentUn comentario en una PR o una incidencia
  • issuesUna incidencia cambia
Los elige Agentry y son los que hacen falta para seguir una PR; no se pueden cambiar aquí.
Agentry genera un secreto de 32 bytes, lo guarda y se lo entrega a GitHub al registrar el webhook. No se vuelve a mostrar. Si el repositorio ya tiene un webhook con esta dirección, Agentry lo adopta en lugar de crear otro. Registrarlo necesita permiso de administración sobre el repositorio.
